# Klik Desktop 1.0.9

## [Download the complete Klik Desktop DMG](https://minervacap2022.github.io/klik-desktop-releases/download.html)

This release makes the public installer and the installed version unambiguous and adds verified desktop OTA updates.

### What changed

- Settings shows the installed version and latest available version.
- Klik checks a stable `latest.json` feed instead of treating an old immutable DMG URL as “latest.”
- Large update ZIPs resume with HTTP Range after a connection closes.
- Downloads are verified by exact byte size and SHA-512.
- Extracted updates are checked for bundle ID, target version, and valid code signature.
- Installation atomically replaces the app, relaunches Klik, and preserves `~/.klik` data.

### End-to-end acceptance

A signed Klik 1.0.8 install discovered 1.0.9, downloaded and verified the complete 5.2 GB OTA package, replaced itself, relaunched as 1.0.9, preserved the local product store, and then reported itself current against the public feed.
