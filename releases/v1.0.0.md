## Klik Desktop 1.0.0

First public Klik Desktop release for Apple Silicon Macs.

### Included
- Fully local Klik desktop application
- Bundled Whisper speech-to-text runtime and model
- Bundled Qwen3 8B local language model and llama.cpp runtime
- Local Sessions, People, Projects, Minutes, Todos, Day Map, and Ask Klik
- English and Simplified Chinese interface

Built from private source revision `e5452c7ed90253410cc549f0775917c2a1e0ec5a` on 2026-09-09.

### Download

**[Download the complete Klik Desktop DMG (5.3 GB)](https://minervacap2022.github.io/klik-desktop-releases/download.html)**

This single download includes the application, Whisper model, Qwen3 model, and both local runtimes. Open the DMG and drag Klik into Applications.

GitHub's numbered parts remain available only as a fallback because GitHub limits each individual release asset to 2 GiB.

### Requirements
- Apple Silicon Mac (`arm64`)
- For recording conversion: `brew install ffmpeg`

### Signing
This build is ad-hoc signed and is not notarized. On first launch, Control-click Klik and choose **Open** if macOS displays a verification warning.
