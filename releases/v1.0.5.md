# Klik Desktop 1.0.5

## [Download the complete Klik Desktop DMG](https://minervacap2022.github.io/klik-desktop-releases/download.html)

Fixes the new-install Ask Klik experience:

- Ask Klik now loads the session catalog when opened.
- A fresh install with no sessions shows a localized first-session empty state.
- The app no longer exposes `Error invoking remote method 'klik-api:ask'` when there is no local session data.
- Includes all previously merged desktop product-parity and live-recording work.

Platform: macOS Apple Silicon (`arm64`)
